Two-Sentence Explanation
The input name is the key PHP uses to read a submitted value from $_POST, while the id links a form control to its label and identifies that control in the page. An unchecked checkbox is not included in the submitted form data, so if no toppings are selected, PHP should handle the missing toppings[] value as an empty list.

Critical-Thinking Response
I would reject the whole request if it contains even one topping that is not on the allowed list. Client-side checks can be bypassed by changing the page or sending a custom request, so checking every topping on the server and rejecting an invalid submission keeps the ticket consistent and lets the user correct the choice.
